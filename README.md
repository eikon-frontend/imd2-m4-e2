# M4-E2 : deux grilles, deux formats

Le HTML, les couleurs et les hauteurs minimales sont déjà en place. Il reste les deux grilles, d'abord en mobile, puis en desktop.

## Démarrer le projet

Dans le terminal de VS Code, à la racine du projet :

```bash
npm install
npm start
```

## Ce qu'il y a à faire

Dans `src/style.css`, complétez les règles marquées `à compléter`. Une seule media query, déjà ouverte dans le fichier.
